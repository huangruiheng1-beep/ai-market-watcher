# 离线演示数据说明

本目录包含一份公开市场观察样例，用于无 API Key 环境下验证工具 5 的信号接入和 HTML 报告生成。

- 行情数据截至：`2026-08-18`
- 报告生成日：`2026-08-19`
- 范围：纳斯达克 100 市场观察结果
- 不包含：API Key、账户信息、持仓信息、买卖指令

文件：

- `nd100_resonance_demo.csv`：多周期共振结果。
- `five_rankings_demo.csv`：五榜单结果。
- `divergence_td9_demo.csv`：背离 + TD9 子集。
- `skdj_demo.csv`：SKDJ 观察池。
- `status_chain_board_real_sample.html`：当日真实数据状态看板样例。

这些样例只用于展示软件工作流，不代表当前实时市场状态。
