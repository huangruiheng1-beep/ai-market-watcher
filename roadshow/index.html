01 · 问题Problem

数据很多，但今天先看谁没有答案。 Lots of data, but who to look at first has no answer.

指标脚本给你一个数字，研报给你一个结论。但今天该优先复核哪只、它这几天走到了哪一步、什么时候该停止观察——这些过程性的问题，最容易丢。 Indicator scripts give a number, sell-side reports give a conclusion. But which ticker to review first today, what step it has reached across days, and when to stop watching—these process questions keep getting lost.

01

指标很多Many indicators

RSI、MACD、TD9、SKDJ、多周期——每天都能算出一堆，但谁优先看？RSI, MACD, TD9, SKDJ, multi-timeframe—plenty computed daily, but which first?

02

报告很多Many reports

每日 PDF、Excel、截图，但跨天以后哪只还在观察、哪只已经失效，没有记忆。Daily PDFs, sheets, screenshots—yet across days nothing remembers which ticker is still under watch or already failed.

03

顺序丢了Order is lost

工具的价值不是给出"买/卖"，而是把查看顺序和状态过程整理出来，留下可回放的研究记忆。The value isn't a buy/sell call—it's organising the watch order and state process into replayable research memory.

03 · 五个工具 + 下一阶段Five Tools + Roadmap

指标是证据，
状态是过程。 Indicators are evidence,
state is the process.

当前五个工具各自提供证据，状态链把证据串成可回放的研究过程。下一阶段会增加 7 天复盘工具；它现在是规划项，不是本版已交付功能。 The five shipped tools supply evidence; the status chain stitches it into a replayable process. A 7-day review tool is planned next; it is not part of this delivered version yet.

TOOL 01 多周期共振Multi-timeframe resonance

方向是否一致Is direction aligned

60 分钟、日线、周线是否形成一致的观察背景。输出分层与行情截至日期，数据不足会明确标出。Whether 60-min, daily, and weekly form a consistent observation backdrop. Outputs layering and data-as-of; insufficient data is flagged.

TOOL 02 五榜单Five rankings

今天先看谁Who to watch today

标的很多时，把它们分到不同查看顺序：已确认、背离观察、强趋势待触发、潜力、风险噪音。When tickers pile up, sort them into watch orders: confirmed, divergence-watch, strong-trend-pending, potential, risk-noise.

TOOL 03 背离 + TD9Divergence + TD9

动能是否疲劳Is momentum tired

价格与动能是否出现值得人工复核的异常组合。它是观察提示，不是反转预测。Whether price and momentum show anomalous combos worth manual review. It is an observation hint, not a reversal forecast.

TOOL 04 SKDJSKDJ

属于哪类场景Which scenario

超跌、回调、超买或普通区，当前处于哪种观察场景。候选公式与数据不足必须明确标出，不包装成已验证指标。Oversold, pullback, overbought, or neutral—which scenario applies now. Candidate formulas and insufficient data are flagged, never dressed as verified.

TOOL 05 状态链Status chain

走到哪一步Which step reached

这只股票跨几天走到哪一步，何时失效或继续观察。状态机记录 OBSERVE → BASE → TRIGGER → CONFIRM，失效优先于预测。Which step a ticker has reached across days, when it fails or keeps being watched. State machine logs OBSERVE → BASE → TRIGGER → CONFIRM; invalidation precedes prediction.

NEXT · PLANNED 7 天复盘工具 · 规划中7-day review · planned

一周以后，复盘这条观察链Review the observation chain after a week

汇总 7 天内的信号、状态变化、失效与人工复核记录，形成可回放的复盘报告。当前版本尚未实现，只先在产品路线中占位。Summarise seven days of signals, state changes, invalidations, and manual reviews into a replayable report. Not implemented in v0.1.0; shown here as the next product milestone.

安装说明Installation

本地双击或 GitHub Pages 都能用，断网也能打开。Works locally and on GitHub Pages, even offline.

  1. 克隆仓库Clone the repo
    git clone <GitHub 仓库地址>
  2. 进入目录Enter the directory
    cd ai-market-watcher
  3. 创建虚拟环境Create a venv
    python3 -m venv .venv
  4. 激活环境Activate it
    source .venv/bin/activate
  5. 安装依赖Install dependencies
    python -m pip install -r requirements.txt
  6. 运行演示（离线备用）Run the demo (offline fallback)
    python run_demo.py

API 获取说明API Setup

真实行情来自 Twelve Data，免费额度即可起步。Live quotes come from Twelve Data; the free tier is enough to start.

  1. 访问官方价格页Open the pricing page

  3. 把 Key 放进本地 .env 或受保护凭据文件Put the key in local .env or a protected credentials file
  4. 确认 Key 不进代码、报告或 GitHubMake sure the key never enters code, reports, or GitHub

08 · 边界与收束Boundaries

它是研究工作流，
不是自动交易系统。 It's a research workflow,
not an auto-trading system.

✕

不预测涨跌No price prediction

只输出查看顺序与状态，不给方向判断。Only outputs watch order and state, never direction calls.

✕

不连接券商No broker link

不接交易接口，不下传输单。No trading interface, no order routing.

✕

不自动下单No auto-orders

所有动作都需要人工确认与执行。Every action needs manual confirmation and execution.
